# Code of Conduct

## Our standard

Participation in Venice Fyr should remain professional, technically focused and free of harassment.

Expected behavior includes:

- treating contributors and users with respect;
- discussing code and decisions rather than attacking people;
- accepting technical review and correction;
- giving actionable feedback;
- respecting privacy and coordinated security disclosure;
- avoiding discriminatory, threatening, sexualized or harassing conduct;
- not publishing another person's private information without permission.

## Scope

This applies in project-controlled spaces including issues, pull requests, discussions, review threads and other official collaboration channels.

## Enforcement

Project maintainers may edit, hide, reject or remove contributions and may temporarily or permanently restrict participation when behavior is disruptive, abusive, unsafe or inconsistent with this standard.

Enforcement decisions should consider context, severity, repetition and project safety.

## Reporting conduct issues

Do not use public threads to expose sensitive personal details.

Report conduct problems privately to a repository maintainer through an available private GitHub contact path. If no private channel is configured, request one without posting sensitive evidence.

Maintainers should handle reports with appropriate confidentiality and avoid retaliation against good-faith reporters.
