# Branding Assets

This documentation pack includes lightweight candidate assets for the repository.

## Files

- `docs/assets/venice-fyr-banner.png` — README hero banner.
- `docs/assets/venice-fyr-banner.svg` — scalable source.
- `docs/assets/venice-fyr-social-preview.png` — GitHub social-preview candidate.
- `docs/assets/venice-fyr-mark.png` — square mark.
- `docs/assets/venice-fyr-mark.svg` — scalable mark.

## Direction

The visual concept uses:

- near-black Android-friendly background;
- warm ember/orange signal light;
- Scandinavian `fyr` (lighthouse/beacon) motif;
- restrained technical grid/beam elements;
- minimal typography suitable for GitHub.

The assets deliberately avoid copying Venice.ai logos or claiming official brand affiliation.

## Before adoption

The implementing agent must:

1. inspect any existing app/brand assets;
2. verify trademark/brand constraints;
3. compare the candidate mark with the actual Android launcher icon direction;
4. keep README asset paths valid;
5. optimize file sizes if necessary;
6. set GitHub's social preview manually if desired — committing the image does not automatically configure repository social-preview settings.

These files are candidates, not a mandate to replace stronger existing assets.
